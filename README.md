# wish

Простий Unix-shell на C++ (OSTEP `processes-shell`).

## Збірка та запуск

```
make
./wish            # інтерактивний режим
./wish batch.txt  # пакетний режим
```

## Можливості

- Вбудовані: `exit`, `cd`, `path`
- Зовнішні команди через `fork` + `execv`
- Переспрямування: `cmd > file`
- Паралельні команди: `cmd1 & cmd2`
